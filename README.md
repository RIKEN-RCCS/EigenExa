EigenExa
===============

To build the library, do as follows.

 * ./bootstrap
 * ./configure
 * make

For further information, please read the user's manual in doc/.

NOTE: This repository version based on EigenExa version 2.12.
      dir_{213,old} are just included as for reference or comparison.
      dir_213 come from the version 2.13.
      dir_old come from the older revision by Mr. Hayashi for C++ refactoring with version 2.12
